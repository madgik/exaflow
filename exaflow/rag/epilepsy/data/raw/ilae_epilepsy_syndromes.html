Classification and Definition of Epilepsy Syndromes

Source snapshot for the epilepsy RAG MVP based on the ILAE syndrome classification page and intended for local retrieval prototyping.

Purpose

ILAE states that syndrome classification helps clinical recognition, supports high-yield diagnostic investigation, guides optimal therapy, and improves prognosis communication.

Definition of Epilepsy Syndromes

Epilepsy syndromes are defined as clusters of clinical features that tend to occur together, including seizure types, age at onset, EEG features, imaging findings, comorbidities, and expected course.

Structure of the Syndrome Papers

The ILAE syndrome framework is divided into syndromes with onset in neonates and infants, syndromes with onset in childhood, syndromes with onset at a variable age, and idiopathic generalized epilepsy syndromes.

Methodology

The syndrome classification project includes a methodology paper and a list of recognized syndromes. Together, these documents define how syndrome terminology should be used in a consistent clinical framework.

Clinical Value

The syndrome approach is intended to refine diagnosis, tailor treatment, inform prognosis, and support communication about epilepsy course and comorbidity risks.

Governance

In an epilepsy RAG system, these ILAE syndrome documents should be treated as primary sources for syndrome definitions and source-of-truth terminology.
